# Route Inventory

This is the current app surface detected in the Lovable repo. The target routes will be recreated in Next.js with the same product meaning and a cleaner backend contract.

## Public

- `/` -> Landing page
- `/login` -> Player login
- `/subscribe` -> Subscription entry flow
- `/renew` -> Renewal flow
- `/onboarding` -> New player onboarding
- `/verify` -> Phone or account verification

## Player App

- `/app` -> Player home/dashboard
- `/checkmate` -> CheckMate game
- `/wisdomdrop` -> WisdomDrop game
- `/profile` -> Player profile and rank
- `/entries` -> Entry history / ticket ledger
- `/results` -> Session results
- `/leaderboard` -> Leaderboard
- `/winners` -> Winners archive
- `/kyc` -> Prize claim and KYC flow

## Admin

- `/admin/login` -> Admin login
- `/admin` -> Admin dashboard
- `/admin/draw` -> Draw operations
- `/admin/winners` -> Winner management
- `/admin/players` -> Player list
- `/admin/players/:playerId` -> Player detail
- `/admin/missions` -> Mission management
- `/admin/banners` -> Banner management
- `/admin/config` -> Platform config
- `/admin/help` -> Help and operational notes

## API

- `/api/forthsoft-webhook` -> Existing webhook entry point
